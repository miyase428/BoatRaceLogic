# 平和島（HWJ）コースサイン v1 ゼロベース再監査まとめ

## 結論

- 本番反映は**まだ行っていない**。本資料は、既存の従来ML v1方式における本番反映候補の整理である。
- 現行統計サインのまま維持する用途: **1C first / 1C top3 / 2C first / 3C top2 / 4C first**。
- 現行統計サインからMLへ部分置換する価値がある候補: **1C top2、2C top2・top3、3C first・top3、4C top2・top3**。
- 現行主サインがない外枠で、新規ML候補として強い用途: **5C first・top2・top3、6C top2・top3**。**6C first**は絶対的な1着率と月別の揺れを考慮して見送り寄り。

  - 現行主サインがない用途は、事前固定の5/10/15/20%表示率で全体基礎率との差を比較する。
- 既存のKRY/SME/BWKと同じ、36か月・6か月VALID・6か月TESTの共通監査条件を使用した。ASY/AMGの新7モデル比較方式は使用していない。

## 読み取り

- 最も改善が大きい既存サインは4C top2（+17.50pt）と4C top3（+15.00pt）。ただし母数は各80件なので、採用時は前方追跡を特に重視する。
- 2C top2/top3、3C first/top3、1C top2も、同数比較で95%以上の改善確率を満たす。
- 5C top2/top3と6C top3は、主サインがない状態からでも月別の一貫性が最も明瞭。5C firstと6C top2も候補だが、既存サインがないため本番化後の前方追跡を必須とする。
- 1C first/top3、2C first、3C top2はゼロベース監査だけなら改善的に見える項目もあるが、**同数比較が95%に届かない**。既存統計サインの置換根拠としては弱いので残す。
- 4C firstはML同数比較で悪化したため、現行統計サインを維持する。
- 6C firstは相対的な改善はあるが、絶対率が5.41%と低く、月別で2か月が基礎率を上回らなかった。表示を増やす根拠としては不足する。
